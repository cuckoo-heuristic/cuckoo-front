## Usage
**Requirements:** `node`, `nvm`

### Installation

1: nvm
```bash
nvm use
```
2: Install Dependencies
```bash
npm install
```
3: Compile and Run the project
```bash
ng serve
# or
npm run dev
```

> [!WARNING]
> Currently, this project is not connected to the CUCKOO-CORE APIs and cannot be used with the current backend.
